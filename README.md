A personal software engineering portfolio built with plain HTML, CSS, and JavaScript. No frameworks, no build step — works directly with GitHub Pages.


## Before publishing, replace:

- `images/profile.jpg` — your photo
- `images/project1.png` … `project5.png` — real project screenshots
- `CV/Kalisa_Ineza_Jovith_CV.pdf` — your actual CV
- In `index.html`: bio text, education, experience, certificate details, and every `href="#"` GitHub/live-demo link, plus the email, phone, GitHub, and LinkedIn links in the Contact section.

## Publish with GitHub Pages

1. Create a new GitHub repository (e.g. `portfolio`).
2. Upload all files in this folder, keeping the same structure (`images/`, `CV/` included).
3. On GitHub, go to **Settings → Pages**.
4. Under **Build and deployment → Source**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then **Save**.
6. Wait 1–2 minutes, then refresh — GitHub will show your live URL, typically:
   `https://<your-username>.github.io/<repo-name>/`
